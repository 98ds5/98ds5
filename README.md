### 🔍 What I care about

- **Testability as a design constraint** — e.g. pluggable embedding layer so the whole retrieval
  pipeline is testable without a GPU, a model download, or network access.
- **Failure should be loud** — mixing vectors from two different models must raise, not silently
  return meaningless similarity scores.
- **Understand every line** — I use AI-assisted coding, but review, debug and take responsibility
  for each decision in my projects.
